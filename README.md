# Diário de Bordo — Consciência Negra

## Sobre o projeto

Este site foi desenvolvido como parte de uma atividade avaliativa do curso Técnico Integrado em Informática do IFBA – Campus Eunápolis, com o objetivo de registrar, documentar e refletir sobre as experiências vivenciadas durante o evento da Consciência Negra.

O projeto reúne relatos, reflexões e registros fotográficos das atividades realizadas, valorizando a história, a ancestralidade, a identidade e o protagonismo da população negra.

## Objetivos

- Documentar as experiências e os conhecimentos adquiridos durante o evento.
- Preservar memórias por meio de textos e registros fotográficos.
- Promover reflexões sobre questões históricas, sociais e culturais.
- Aplicar conhecimentos de desenvolvimento web em um projeto educacional.

## Tecnologias utilizadas

- **HTML5** — Estruturação das páginas.
- **CSS3** — Estilização e identidade visual.
- **JavaScript** — Funcionalidades e interatividade.

## Funcionalidades

- Diário de bordo organizado em relatos.
- Galeria de registros fotográficos em formato mosaico.
- Interface com identidade visual inspirada na cultura afro-brasileira.
- Navegação entre páginas e conteúdos.

## Finalidade

Mais do que um registro acadêmico, este projeto busca transformar experiências em memória, conhecimento em reflexão e aprendizado em consciência social.
