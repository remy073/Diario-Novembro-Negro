# Raízes & Vozes — site atualizado

## Como abrir
Abra `index.html` no navegador ou pelo Live Server do VS Code.

## IMPORTANTE: imagens
Os arquivos de imagem não foram enviados nesta conversa. **Copie sua pasta `image/` original para esta pasta**, preservando os nomes:
- `image/BannerPTG.png` — banner principal
- `image/ifbalogo.png` — logotipo do menu
- `image/grupo.png` — ícone do grupo
- `image/mesaaberta.jpeg` — foto do registro

O link `sobre.html` foi mantido como no arquivo original, mas sua página não foi enviada.

## Onde editar
- `style.css` — seções 15 e 16: navegação, banner maior, cartões dos registros e ajustes para celular.
- `style.css` — `.hero-art` para ajustar altura e posição do banner.
- `index.html` — `.intro-card` para o texto de apresentação; seção `#registros` para os diários.
- `script.js` — criação de registros e armazenamento no navegador (`localStorage`).
